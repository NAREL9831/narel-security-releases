# ナレルセキュリティ（配布用）

パソコンを見張って、怪しいものを知らせてくれるアプリです。デスクトップの友だち「ちびとも」も一緒に入ります。
ここにはインストーラーだけを置いています（ソースコードは入っていません）。

## 入れかた

1. 右の「Releases」から、いちばん新しい `NarelSecurity-Setup-v○○.exe`（ナレルセキュリティのインストーラー） をダウンロードします
2. ダウンロードしたファイルを開きます
3. 「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を押します（まだ会社の証明をつけていないテスト版のためです）
4. 「入れていい？」で「はい」を押します

## 知っておいてほしいこと

- **テスト版**です。はじめは「見守り」（怪しいものを見つけても止めずに、知らせるだけ）で動きます
- パソコンの中で動くAIが入っています。はじめに1〜19GBのAIのデータをダウンロードします（外には何も送りません）
- 消すときは、Windowsの「設定」→「アプリ」から「ナレルセキュリティ」を選んで消します
- 中に入っているAIの部品（Ollama）は MIT ライセンスです。くわしくは、入れたフォルダの `AI\ライセンス.txt` を見てください
